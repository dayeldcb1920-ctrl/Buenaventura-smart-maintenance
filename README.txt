BUENAVENTURA | SMART MAINTENANCE

Prototipo académico de mantenimiento predictivo para camiones mineros.

IMPORTANTE:
- Utiliza datos sintéticos/simulados, no datos reales de Buenaventura.
- No debe emplearse para decisiones operativas reales.
- El modelo y sus umbrales son demostrativos y requieren validación con datos reales y especialistas.

EJECUCIÓN LOCAL:
1. Instalar Python.
2. Abrir una terminal en esta carpeta.
3. Ejecutar: pip install -r requirements.txt
4. Ejecutar: streamlit run app.py
5. Abrir la dirección local que muestra Streamlit.

PUBLICACIÓN EN LA NUBE:
Subir app.py y requirements.txt a un repositorio GitHub y desplegarlo
desde Streamlit Community Cloud, seleccionando app.py como archivo principal.
